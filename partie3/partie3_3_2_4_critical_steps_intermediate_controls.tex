\subsubsection{Controls of Critical Steps and Intermediate Steps}

\paragraph{General}

The manufacturer documentation available for the
\textbf{BN-100 LUX} identifies components, assemblies and functions
relevant to the safety and performance of the finished device.

The applicable risk-management documentation also addresses
manufacturing-process-related risks.

The documentation available for this submission does not provide a
separate detailed set of manufacturing-stage acceptance criteria,
intermediate-product specifications or inspection records for each
individual production step.

Accordingly, this section describes the documented critical
components, assemblies and safety-related functions without
introducing unsupported manufacturing controls or acceptance
criteria.

% ============================================================
% Mechanical Assemblies
% ============================================================

\paragraph{Mechanical Assemblies}

The manufacturer documentation identifies the following principal
mechanical assemblies:

\begin{itemize}
    \item the base structure incorporating aluminium alloy
    extrusions;
    \item the infant crib incorporating steel components;
    \item the crib inclination mechanism;
    \item the Plexiglas protective panels;
    \item mobile castors, where provided; and
    \item associated supporting structures.
\end{itemize}

The documented manufacturing operations include processing,
welding and surface spraying of relevant structural components.

These operations are considered within the manufacturer's
manufacturing and quality-management framework. However, separate
intermediate-product acceptance criteria and inspection limits for
the individual mechanical manufacturing operations are not detailed
in the available documentation.

% ============================================================
% Radiant Heating Assembly
% ============================================================

\paragraph{Radiant Heating Assembly}

The radiant heating assembly incorporates components identified in
the manufacturer documentation, including:

\begin{itemize}
    \item aluminium alloy structural components;
    \item stainless steel reflector;
    \item fixed explosion-proof quartz infrared heating tube;
    \item protective net; and
    \item adjustable-angle LED white light.
\end{itemize}

The applicable risk-management documentation identifies the air
heater as a critical component.

The heating assembly is therefore considered a safety-relevant
assembly within the manufacturer's production, quality-management
and risk-management processes.

A separate detailed intermediate inspection procedure or acceptance
record specifically applicable to this assembly is not provided in
the documentation available for this submission.

% ============================================================
% Temperature Monitoring System
% ============================================================

\paragraph{Temperature Monitoring System}

The \textbf{BN-100 LUX} incorporates a skin temperature sensor
identified by the manufacturer as model \textbf{T10-AS}.

The applicable risk-management documentation identifies the sensor
as a critical component. Documented characteristics relevant to
temperature monitoring include:

\begin{itemize}
    \item skin temperature sensor precision:
    \(\leq 0.3\,^\circ\mathrm{C}\);
    \item sensor short-circuit alarm; and
    \item sensor open-circuit alarm.
\end{itemize}

The sensor is therefore considered a safety-related component of
the temperature monitoring system.

A separate production-stage inspection procedure or acceptance
record specifically applicable to this sensor is not provided in
the available documentation.

% ============================================================
% Electrical and Electronic Components
% ============================================================

\paragraph{Electrical and Electronic Components}

The applicable risk-management documentation identifies the
following critical components:

\begin{itemize}
    \item dual-fuse input socket;
    \item power supply cord;
    \item auxiliary socket outlets;
    \item relay;
    \item rocker switch;
    \item fuse;
    \item rechargeable battery;
    \item optocoupler;
    \item printed circuit board;
    \item internal wiring;
    \item skin temperature sensor;
    \item air heater;
    \item thyristors;
    \item audible alarm;
    \item switching power supply; and
    \item electrical filter.
\end{itemize}

The manufacturer documentation associates these components with
their respective component references and, where applicable,
technical or certification information. Their identification
supports consideration within the manufacturer's production,
assembly and risk-control framework.

Separate production inspection records and individual acceptance
criteria for the integration of each component are not provided
in the documentation available for this submission.

% ============================================================
% Safety-Related Functions
% ============================================================

\paragraph{Safety-Related Functions}

The applicable risk-management documentation identifies the
following safety-related characteristics of the
\textbf{BN-100 LUX}:

\begin{itemize}
    \item over-temperature protection with heating cut-off and
    audible and/or visual alarm;
    \item temperature deviation alarm;
    \item skin temperature sensor short-circuit and open-circuit
    alarms;
    \item power failure alarm; and
    \item manual-mode alarm.
\end{itemize}

These characteristics form part of the manufacturer's documented
risk-control framework.

The available documentation does not provide a complete
production-stage verification procedure for each safety-related
function. No additional verification method, acceptance criterion
or production record is therefore specified in this section unless
supported by the applicable manufacturer documentation.

% ============================================================
% Manufacturing Process Risk Control
% ============================================================

\paragraph{Manufacturing Process Risk Control}

The manufacturer's applicable risk-management documentation
includes manufacturing-process risk assessment within the overall
risk-management activities.

It also states that production and post-production activities are
to follow the applicable processes, methods and measures established
by the manufacturer, including, where applicable, product
change-control and customer-feedback-control processes.

This documentation provides the basis for considering
manufacturing-process-related risks associated with the finished
device.

% ============================================================
% Intermediate Products and Assemblies
% ============================================================

\paragraph{Intermediate Products and Assemblies}

The manufacturer documentation describes the principal components
and assemblies of the \textbf{BN-100 LUX}, but does not provide a
separate formal classification of intermediate products or a
complete list of intermediate-product specifications.

Accordingly, no additional intermediate products, manufacturing-stage
specifications or acceptance criteria are introduced in this
section.
