\subsubsection{Specifications}

\paragraph{General}

The specifications of the finished \textbf{BN-100 LUX} Infant Radiant
Warmer are based on the applicable manufacturer documentation
available for the device.

They cover the documented electrical, environmental, thermal,
alarm, storage and mechanical characteristics.

% ============================================================
% Electrical Specifications
% ============================================================

\paragraph{Electrical Specifications}

The manufacturer documentation specifies the following electrical
characteristics:

\begin{itemize}
    \item Rated supply voltage: \(220 \pm 22\,\mathrm{V}\);
    \item Rated frequency: \(50 \pm 1\,\mathrm{Hz}\);
    \item Rated power: \(1000\,\mathrm{VA}\);
    \item Heater power: \(800\,\mathrm{W}\).
\end{itemize}

% ============================================================
% Environmental Operating Conditions
% ============================================================

\paragraph{Environmental Operating Conditions}

The documented operating conditions are:

\begin{itemize}
    \item Ambient temperature: \(18\text{--}30\,^\circ\mathrm{C}\);
    \item Relative humidity: \(30\text{--}75\,\%\);
    \item Atmospheric pressure: \(700\text{--}1060\,\mathrm{hPa}\);
    \item Air velocity: less than \(0.3\,\mathrm{m/s}\).
\end{itemize}

% ============================================================
% Temperature Control Specifications
% ============================================================

\paragraph{Temperature Control Specifications}

The manufacturer documentation specifies the following
temperature-related characteristics:

\begin{itemize}
    \item Temperature display range: \(10\text{--}45\,^\circ\mathrm{C}\);
    \item Control temperature range: \(32\text{--}38\,^\circ\mathrm{C}\);
    \item Temperature control precision: \(\leq 0.5\,^\circ\mathrm{C}\);
    \item Bed temperature uniformity: \(\leq 2\,^\circ\mathrm{C}\);
    \item Skin temperature sensor precision:
    \(\leq 0.3\,^\circ\mathrm{C}\).
\end{itemize}

The device incorporates a skin temperature monitoring system for
monitoring the newborn's temperature during operation.

% ============================================================
% Alarm and Protection Specifications
% ============================================================

\paragraph{Alarm and Protection Specifications}

The manufacturer documentation identifies the following alarm and
protection characteristics:

\begin{itemize}
    \item Over-temperature protection with heating cut-off and
    audible and visual alarm;
    \item First over-temperature alarm threshold:
    \(39\,^\circ\mathrm{C}\);
    \item Second over-temperature alarm threshold:
    \(40\,^\circ\mathrm{C}\);
    \item Temperature deviation alarm: \(\pm 1\,^\circ\mathrm{C}\);
    \item Skin temperature sensor short-circuit alarm;
    \item Skin temperature sensor open-circuit alarm;
    \item Power failure alarm; and
    \item Manual-mode alarm after 15 minutes.
\end{itemize}

The documented power failure alarm duration is approximately
10 minutes.

The alarm sound level is specified as not exceeding \(80\,\mathrm{dB}\),
with a sound level of at least \(65\,\mathrm{dB}\) at a distance of
\(3\,\mathrm{m}\).

% ============================================================
% Storage Conditions
% ============================================================

\paragraph{Storage Conditions}

The manufacturer documentation specifies the following storage
conditions:

\begin{itemize}
    \item Storage temperature: \(-40\text{--}+55\,^\circ\mathrm{C}\);
    \item Relative humidity: not more than \(95\,\%\);
    \item Atmospheric pressure: \(500\text{--}1060\,\mathrm{hPa}\).
\end{itemize}

% ============================================================
% Mechanical Specifications
% ============================================================

\paragraph{Mechanical Specifications}

The manufacturer documentation specifies the following
characteristics for the patient support structure:

\begin{itemize}
    \item Crib inclination: up to \(10^\circ\);
    \item Three-step inclination adjustment;
    \item Mattress maximum load: \(100\,\mathrm{N}\) (\(10\,\mathrm{kg}\));
    \item Tray maximum load: \(20\,\mathrm{N}\) (\(2\,\mathrm{kg}\)).
\end{itemize}

% ============================================================
% Documentary Basis
% ============================================================

\paragraph{Documentary Basis}

The specifications presented in this section are based on the
manufacturer documentation available for the
\textbf{BN-100 LUX} Infant Radiant Warmer, including:

\begin{itemize}
    \item Risk Management Report (BN-100/BN-100A),
    Document No. YF-7.3-24-02 (w), Version A/0; and
    \item BN-100 / BN-100 LUX User Manual.
\end{itemize}

The specifications above are limited to the characteristics
identified in the cited manufacturer documentation.
